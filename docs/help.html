১. পরিচিতি

VYRO হলো একটি ক্লাউড-ভিত্তিক দোকান ম্যানেজমেন্ট অ্যাপ। এটি দিয়ে আপনি সহজে পণ্য, বিক্রি, কাস্টমার, সাপ্লায়ার, খরচ ও রিপোর্ট পরিচালনা করতে পারবেন।

প্রধান সুবিধা:

  • 📱 একাধিক ডিভাইসে sync
  • ☁️ Cloud backup
  • 🌐 অফলাইনেও কাজ করে
  • 🇧🇩 বাংলা + English

২. Activation করা

প্রথমবার ব্যবহারের সময় একটি Activation Code লাগবে।

  1. অ্যাপ খুললে Device ID দেখতে পাবেন (যেমন: DEV7K2M8X9P1)
  2. 📋 Copy Device ID button চেপে copy করুন
  3. Admin-কে WhatsApp/Message করুন
  4. Admin একটি Activation Code দেবেন (যেমন: ACT-1234-ABCD)
  5. Code লিখে ✅ Activate Now চাপুন
⚠️ সতর্কতা: Device ID গোপন রাখুন। এটি অন্য কারো সাথে শেয়ার করবেন না।

৩. Login করা

  1. Select Shop dropdown থেকে দোকান বেছে নিন
  2. Username লিখুন
  3. Password লিখুন (case-sensitive)
  4. 🔐 Login button চাপুন
💡 টিপস: Caps Lock বন্ধ আছে কিনা দেখে নিন। Password ভুল হলে "Wrong username or password" দেখাবে।

৪. ড্যাশবোর্ড

লগইন করার পর যা দেখবেন:

  • ৮টি KPI কার্ড: আজকের বিক্রি, লাভ, বাকি, স্টক মূল্য ইত্যাদি
  • Quick Actions: ১২টি দ্রুত কাজের button
  • Sales Chart: ৭ দিন / ৩০ দিন / বছরের বিক্রির চার্ট
  • Smart Alerts: কম স্টক, বাকি ইত্যাদি সতর্কতা

নিচে Bottom Navigation:

  • 🏠 Home — ড্যাশবোর্ড
  • 📦 Stock — ইনভেন্টরি
  • 👥 Party — কাস্টমার
  • 🧾 Sales — বিক্রি
  • 📊 Reports — রিপোর্ট

৫. পণ্য যোগ করা

  1. নিচে 📦 Stock চাপুন
  2. + Add button চাপুন
  3. তথ্য পূরণ করুন:
    • পণ্যের নাম (আবশ্যক)
    • SKU, Barcode (থাকলে)
    • ক্রয় মূল্য, বিক্রয় মূল্য
    • Stock Qty ও Unit (pcs/kg/box)
    • Low Alert (ডিফল্ট ৫)
  4. 💾 Save চাপুন
✅ সফল হলে পণ্য তালিকায় যোগ হবে এবং cloud-এ sync হবে।

৬. পণ্য এডিট / ডিলিট

এডিট করতে: পণ্যের পাশে ✏️ button → তথ্য পরিবর্তন → 💾 Save

ডিলিট করতে: পণ্যের পাশে 🗑️ button → Confirm

⚠️ ডিলিট করলে সব ডিভাইস থেকে মুছে যাবে।

৭. বিক্রি করা

  1. নিচে 🧾 Sales চাপুন
  2. Search box-এ পণ্যের নামের শুরু লিখুন → পণ্য tap করুন
  3. Cart-এ + / − দিয়ে পরিমাণ ঠিক করুন
  4. Customer select করুন (Cash / নির্দিষ্ট কাস্টমার)
  5. ✅ Complete Sale চাপুন
  6. Discount, VAT, Paid Amount দিন
  7. আবার ✅ Complete Sale চাপুন
✅ সফল হলে ইনভয়েস তৈরি হবে, স্টক কমবে, cloud-এ sync হবে।

৮. ইনভয়েস / PDF / WhatsApp

  • 🖨️ Print: প্রিন্ট প্রিভিউ

  • 🗑️ — ডিলিট

১১. সাপ্লায়ার ও ক্রয় এন্ট্রি

📖 VYRO User Guide

Version: 4.4.0 | Developer: O-FR Pro Software

💡 Tip: Use 🇧🇩 / 🇬🇧 buttons above to switch language. Click any section in the sidebar.

1. Introduction

VYRO is a cloud-based shop management app for managing products, sales, customers, suppliers, expenses, and reports.

Key benefits:

  • 📱 Multi-device sync
  • ☁️ Cloud backup
  • 🌐 Works offline
  • 🇧🇩 Bangla + English

2. Activation

  1. Open app → see Device ID (e.g. DEV7K2M8X9P1)
  2. Click 📋 Copy Device ID
  3. Send to admin via WhatsApp/Message
  4. Receive Activation Code (e.g. ACT-1234-ABCD)
  5. Enter code → ✅ Activate Now
⚠️ Keep your Device ID private.

3. Login

  1. Select shop from Select Shop dropdown
  2. Enter username
  3. Enter password (case-sensitive)
  4. Click 🔐 Login
💡 Check Caps Lock. Wrong password shows "Wrong username or password".

4. Dashboard

  • 8 KPI cards: Today's sales, profit, due, stock value, etc.
  • Quick Actions: 12 shortcut buttons
  • Sales Chart: 7-day / 30-day / yearly
  • Smart Alerts: Low stock, dues, etc.

Bottom Navigation: Home, Stock, Party, Sales, Reports

5. Add Product

  1. Tap 📦 Stock
  2. Tap + Add
  3. Fill in:
    • Product name (required)
    • SKU, Barcode (optional)
    • Buy price, Sell price
    • Stock Qty and Unit (pcs/kg/box)
    • Low Alert (default 5)
  4. Click 💾 Save

6. Edit / Delete Product

Edit: Tap ✏️ next to product → change → 💾 Save

Delete: Tap 🗑️ next to product → confirm

⚠️ Delete removes from all devices.

7. Making a Sale

  1. Tap 🧾 Sales
  2. Type product name in search → tap product
  3. Adjust quantity in Cart with + / −
  4. Select customer (Cash / specific)
  5. Click ✅ Complete Sale
  6. Enter discount, VAT, paid amount
  7. Click ✅ Complete Sale again
✅ Invoice created, stock reduced, synced to cloud.

8. Invoice / PDF / WhatsApp

  • 🖨️ Print: Print preview
  • 📄 Save PDF: Download PDF
  • 📱 WhatsApp: Share via WhatsApp
  • 🖼️ Save Image: Download PNG
  • 🔄 Sale Return: Process return

9. Customer Management

Add: 👥 Party → + Add → fill → Save

Buttons: 📋 Ledger, 📎 Due voucher, ✏️ Edit, 🗑️ Delete

10. Due & Payment

View due: Dashboard "Recent Due Customers" section.

Receive payment:

  1. Tap customer's 📋 button
  2. Click 💵 Receive Payment
  3. Enter amount → confirm

11. Supplier & Purchase

Add supplier: Dashboard → 🚚 Supplier → + Add

Purchase entry: Dashboard → 📥 Purchase Entry → fill → Save

✅ Stock increases, supplier due increases (if unpaid).

12. Expenses

Dashboard → 💰 Add Expense → description, amount, date → Save

13. Quotations

Dashboard → 📋 Create Quotation

  1. Select/enter customer
  2. Add products (Search Stock or Manual)
  3. Set payment terms
  4. 💾 Save Draft OR 🧾 To Invoice

14. Sale Returns

  1. Open invoice from Sales list
  2. Click 🔄 Sale Return
  3. Check items being returned
  4. Set reason and refund method
  5. Click ✅ Complete Return

15. Delivery Challan

Auto-generated with each sale. Open invoice → 🚚 Delivery Challan.

Register: Reports → 🚚 Challan Register

16. Reports

Tap 📊 Reports at bottom.

  • Today — Today's report
  • This Month — Monthly report
  • This Year — Yearly report

17. Historical Search

Settings → 🔍 Historical Record Search

Search by Date / Month / Year / Range / All. Export CSV available.

18. Backup

Settings → 💾 Backup & Restore

  • 📥 JSON Backup: Full backup (restore-able)
  • 📊 Excel/CSV: Multi-sheet reports
  • 🧾 Invoice PDF: All invoices in one PDF
  • ☁️ Google Drive: Cloud upload
⚠️ Backup at least weekly.

19. Settings

Tap ⚙️ icon at top-right.

  • 🏪 Shop Profile: Name, logo, address, phone
  • 🎨 Appearance: Invoice color, font
  • 🧾 Invoice Settings: Prefix, signature, amount-in-words
  • 💰 Sales Settings: Generate/edit invoice
  • 🔐 Security: Change password
  • 💾 Data: Backup & Restore
  • 🎛️ System Control: 30+ feature toggles
  • 👁️ Hide System: Hide UI elements
  • 📏 UOM Master: Edit unit list

20. Troubleshooting

Can't login

  • Check username/password
  • Check Caps Lock
  • Ensure shop is selected
  • Check internet

New data not showing on other device

  • Pull-to-refresh (mobile)
  • Ctrl+Shift+R (PC)
  • Logout → Login

PDF not generating

  • Wait 3 seconds for library load
  • Use Chrome/Edge
  • Try Print option

Data lost

  • Settings → Backup → Restore
  • Check cloud sync

A: Unlimited with same login.

Q: Where is data stored?
A: Browser (local) + Cloud (encrypted).

Q: Works on mobile?
A: Yes. Add to home screen for PWA experience.

Q: Free trial?
A: Yes — 14 days.
